08-relative units

Specify a length relative to another length property.

  • Pixel (px)
  • M (em)
  • X (ex)
  • Root M (rem)
  • Viewport Units height (vh)
  • Viewport Units Width (vw)
  • Large Viewport (lvh|lvw)
  • Small Viewport (dvh|dvw)
  • Dinamic Viewport (dvh|dvw)

Examples:

  • px: 15px
  • em: 1.5em
  • rem: 2rem
  • ex: 2.4ex
