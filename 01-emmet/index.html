01-Emmet

Plugin for faster HTML and CSS coding.

01-Child: >
Creates child elements (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: +
Creates sibling elements .

Example:

section+header+nav ↔️

Result:

<section></section> <header></header> <nav></nav>

03-Multiplication: *
Repeats elemnts miltiple times.

Example:

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-class: .
Creates a class attribute .

Example:

section+header+nav ↔️

menu.mainmenu 🥴

Result:

<menu>class= "mainmenu"></menu> <div class="container"></div>

05-classes: ...
Creates multiple class attributes .

Example:

menu.mainmenu.uppercase.blue

Result:

<menu class = "mainmenu uppercase blue"></menu>

06-identification: #
Creates an ID attribute. .

Example:

nav#navigation123 ↔️

Result:

<nav id = "navigation123"></nav>

07-text: {}
Insert text content .

Example:

p{Lorem ipsum Dolor.} ↔️

a{Click here}

Result:

<p>Lorem Ipsum Dolor.</p> <a href="">Click Here</a>

08-Custom Attribute: [ ]: +
creates custom atributes .

Example:

a[ ´gref=www.youtube.com ]↔️

Result:

<a href=" www.youtube.com"></a>

09-Item Numbering
Añade números consecutivos.

Ejemplo:

ul>li.num$*3 ↔️

section>article.sec$$$*3 ↔️

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

10-Reverse Numbering
Invierte el orden de numeración.

Ejemplo:

ul>li.num$*3

section>article.sec$$$*3

Resultado:

<ul> <li class="num1"></li> <li class="num2"></li> <li class="num3"></li> </ul>

11-Base Numbering
Define un número base para secuencias

Ejemplo:

ul>li.num$@3*4

Resultado:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li> </ul>

12-Climb Up
Sube un nivel.

Ejemplo:

section>article>div^p

Resultado:

<section> <article> <div></div> <p></p> </article>

13-Grouping
Agrupa elementos juntos.

Ejemplo:

(header>nav)+footer

Resultado:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem
Genera texto de relleno.

Ejemplo:

lorem5

Resultado:

<p>Lorem ipsum dolor sit amet.</p>

15-HTML Documents
Crea varios tipos de documentos HTML.

Ejemplo:

html:5

Resultado:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

Ejemplo:

meta:vp
